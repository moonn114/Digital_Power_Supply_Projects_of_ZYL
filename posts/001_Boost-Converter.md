# 基于STM32F103C8T6的120W同步Boost升压变换器设计

## 1. 项目介绍及实物展示

这是一款以 STM32F103C8T6 为主控的全数字闭环 Boost 升压变换器，目标覆盖宽输入范围的直流稳压应用场景。相比传统模拟控制方案，数字控制具有灵活性强、可在线调参、支持复杂控制算法、状态可观测等优势。

| 参数 | 指标 |
|------|------|
| 输入电压 | 18V ~ 32V DC |
| 输出电压 | 24 ~ 50V 可调 |
| 最大输出电流 | 3A |
| 开关频率 | 40 kHz |
| 控制模式 | 恒压 (CV)  |
| 峰值效率 | 94% |
| 主控芯片 | STM32F103C8T6 |

## 2. 拓扑选择与方案设计

**为什么选择同步 Boost？** 
传统异步 Boost 在续流阶段依靠肖特基二极管导通，在 120W / 50V 输出下续流二极管的导通损耗不可忽视。以平均续流电流约 3A 估算，肖特基正向压降 0.4V，则续流损耗约为 1.2W，占额定功率的 1%。采用同步 Boost，将续流二极管替换为 N-MOS 同步管，导通电阻 RDS(on) 约 77mΩ，同等电流下导通损耗降至约 231mW，效率改善显著。系统架构如下：

- **功率级**：同步 Boost 拓扑，MOSFET (IRF540N)
- **驱动**：半桥驱动芯片 IR2104s，带死区时间硬件保护
- **采样**：输出电压经OPA2188构建的差分放大电路进 ADC引脚，单片机通过ADC + DMA+TIM触发实现非阻塞采样
- **控制**：STM32同步采样数据传到PID，PID再输出占空比到定时器1产生 PWM 形成闭环
- **辅助电源**：从输入取电的VIN-12V辅助电源 (LMR51450)和5V-3.3V辅助电源（TPS5430）

## 3. 硬件设计要点

### 3.1 功率电感设计
电感是 Boost 变换器的核心储能元件，其参数直接影响纹波电流与效率。

**感量选取原则** ：不得超过纹波电流的30%设计（满载 3A）

```
// 电感平均电流
Il2 := (Vout_Boost * Io2) / Vin_Boost = 8.333 A

// 1. 电感感量计算
L2 := ( Vin_Boost * (1 - Vin_Boost / Vout_Boost) / (f2 * 0.3 * Io2) ) * ( Vin_Boost / Vout_Boost ) = (1.152 * 10^-4) H

// 2. 电感纹波电流
ΔIl2 := ( Vin_Boost * (1 - Vin_Boost / Vout_Boost) ) / (f2 * L2) = 2.5 A

// 3. 电感峰值电流
Ilp := Il2 + ΔIl2 / 2 = 9.583 A
```

最终选用*铁硅铝磁环* ，22 匝，实测 470uh @ 10A，饱和电流 > 13A。

### 3.2 输出电容选择

输出纹波目标 < 100mVpp。以ESR 引起的纹波为主导：

```
ΔVo2 := 0.1 V

// 1. 由电容容量引起的
Co2 := ( Io2 * (1 - Vin_Boost / Vout_Boost) ) / ( ΔVo2 * f2 ) = (4.8 * 10^-4) F

// 2. 由电容ESR引起的
ESR4 := ΔVo2 / ( (Vout_Boost / Vin_Boost) * Io2 + ( Vin_Boost * (1 - Vin_Boost / Vout_Boost) ) / ( 2 * f2 * L2 ) ) = 0.01 Ω

Cesr4 := (15 * 10^-6 F·Ω) / ESR4 = 0.001 F
```

采用 2 颗 4.7μF MLCC (X7R) + 3 颗 330μF *高频电解电容*并联，总 ESR 小于0.01mΩ。

### 3.3 PCB Layout 注意事项
功率回路面积最小化是开关电源 PCB 设计的第一原则，直接决定 EMI 和开关损耗。

**关键布局策略：**
- 输出电容 → 上管 → 下管 → 地 功率回路面积最小化
- 开关节点 (SW) 铜皮面积尽量小，减少 EMI
- 模拟地与功率地单点连接（在采样电阻 GND 端汇合）
- 栅极驱动走线尽量短粗

### 3.4 电压采样电路
本设计采用 OPA2188 搭建差分采样电路，对输出电压进行精密衰减后送入 STM32 ADC。

OPA2188 是一款零漂移运算放大器，典型偏置电流仅 200pA，低频噪声密度 8.8nV/√Hz，非常适合对直流精度有要求的采样场景。

差分采样结构的优势在于：即便 GND_power 和 GND_control 之间存在数十毫伏的电位差，差分输入可以将其作为共模信号抑制，而单端采样则会将其直接叠加到采样值上导致测量误差。

放大倍数由R7,R8,R9,R10这四个电阻共同决定，放大比G=R7/R8=R10/R9。二极管用于钳位，防止流进单片机引脚为负电压

## 4. 数字控制策略

### 4.1 控制架构

分层状态机：利用状态机将电源工作分成5个状态，各状态之间的转换条件和输出行为完全解耦，调试时可以精确定位问题出在哪个状态。

中断驱动控制环： ADC 读取 → 状态机调度 → PI 计算 → PWM 更新
### 4.2 PID 数字实现

采用位置式 PI 控制器（不含微分项，因为 Boost 系统本身存在 RHP 零点，加 D 项容易激励高频不稳定）

## 6. 问题与改进

### 问题 1: 纹波偏大

**现象**：输出纹波接近500mv，与计算有偏差。

**原因**：输出电容容值不够大

**解决**：换上更大的电容，最终将纹波成功控制在200mv
### 问题 2: 启动过冲

**现象**：上电瞬间输出电压过冲约 2V。

**原因**：积分器在上电前已饱和。

**解决**：使能输出前将积分器清零，并使能软启动斜坡。

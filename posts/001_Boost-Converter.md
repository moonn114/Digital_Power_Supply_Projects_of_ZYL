# 基于STM32F103C8T6的120W同步Boost升压变换器设计

## 1. 项目介绍及实物展示

本项目旨在设计一款高性能数字控制 Buck 降压变换器，用于实验室通用直流电源。相比传统模拟控制方案，数字控制具有灵活性强、可在线调参、支持复杂控制算法等优势。

| 参数 | 指标 |
|------|------|
| 输入电压 | 18V ~ 32V DC |
| 输出电压 | 24 ~ 50V 可调 |
| 最大输出电流 | 3A |
| 开关频率 | 40 kHz |
| 控制模式 | 恒压 (CV)  |
| 峰值效率 | 94% |
| 主控芯片 | STM32F103C8T6 |

## 2. 拓扑选择与方案设计

选用**同步整流 Boost** 拓扑，上下管均使用 N-MOSFET，相比异步 Boost 在满载时损耗降低。系统架构如下：

- **功率级**：同步 Boost 拓扑，MOSFET (IRF540N)
- **驱动**：半桥驱动芯片 IR2104s，带死区时间硬件保护
- **采样**：输出电压经OPA2188构建的差分放大电路进 ADC
- **控制**：STM32F103C8T6 定时器1产生 PWM，片内 12-bit ADC 同步采样
- **辅助电源**：从输入取电的VIN-12V辅助电源 (LMR51450)和5V-3.3V辅助电源（TPS5430）

## 3. 硬件设计要点

### 3.1 功率电感设计

电感值按 30% 纹波电流设计（满载 3A）：

```
// 电感平均电流
Il2 := (Vout_Boost * Io2) / Vin_Boost = 8.333 A

// 1. 电感感量计算
L2 := ( Vin_Boost * (1 - Vin_Boost / Vout_Boost) / (f2 * 0.3 * Io2) ) * ( Vin_Boost / Vout_Boost ) = (1.152 * 10^-4) H

// 2. 电感纹波电流
ΔIl2 := ( Vin_Boost * (1 - Vin_Boost / Vout_Boost) ) / (f2 * L2) = 2.5 A

// 3. 电感峰值电流
Ilp := Il2 + ΔIl2 / 2 = 9.583 A
```

选用铁硅铝磁环 ，22 匝，实测 470uh @ 10A，饱和电流 > 13A。

### 3.2 输出电容选择

输出纹波目标 < 50mVpp。ESR 引起的纹波为主导：

```
ΔVo2 := 0.1 V

// 1. 由电容容量引起的
Co2 := ( Io2 * (1 - Vin_Boost / Vout_Boost) ) / ( ΔVo2 * f2 ) = (4.8 * 10^-4) F

// 2. 由电容ESR引起的
ESR4 := ΔVo2 / ( (Vout_Boost / Vin_Boost) * Io2 + ( Vin_Boost * (1 - Vin_Boost / Vout_Boost) ) / ( 2 * f2 * L2 ) ) = 0.01 Ω

Cesr4 := (15 * 10^-6 F·Ω) / ESR4 = 0.001 F
```

采用 4 颗 47μF MLCC (X7R) + 3 颗 330μF 固态电解并联，总 ESR 约0.01mΩ。

### 3.3 PCB Layout 注意事项

- 功率回路面积最小化：输入电容 → 上管 → 下管 → 地，环路面积 < 1cm²
- 开关节点 (SW) 铜皮面积尽量小，减少 EMI
- 模拟地与功率地单点连接（在采样电阻 GND 端汇合）
- Gate 驱动走线短且宽，源极开尔文连接

## 6. 问题与改进

### 问题 1: 轻载振荡

**现象**：输出电流 < 500mA 时，输出电压出现约 2kHz 的低频振荡。
**原因**：轻载进入 DCM 模式后，小信号模型发生变化，原 PI 参数不再适用。
**解决**：加入**增益调度** — 根据负载电流自动调整 PI 参数。轻载时降低 Ki 为满载值的 1/4。

### 问题 2: 启动过冲

**现象**：上电瞬间输出电压过冲约 2V。
**原因**：积分器在上电前已饱和。
**解决**：使能输出前将积分器清零，并使能软启动斜坡。

## 7. 总结

本项目实现了一款基于 STM32F334 的全数字控制同步 Buck 变换器，达到了预期指标。数字双环控制 + HRTIM 高分辨率 PWM 的组合在动态响应和稳态精度上都优于传统模拟方案。后续计划加入 CAN 总线通信，实现多机并联均流。

# STM32G474RBT6控制的四开关Buck-Boost电路

## 1. 项目背景与需求

在电池供电和宽输入电压范围的应用场景中，传统 Buck 或 Boost 变换器无法在输入电压跨越输出电压时高效工作。本项目设计一款基于 **STM32G474RBT6** 数字控制的四开关 Buck-Boost 变换器，支持升降压无缝切换，适用于电池充放电、太阳能 MPPT、USB PD 等场景。

| 参数 | 指标 |
|------|------|
| 输入电压 | 12V ~ 55V |
| 输出电压 | 0.5V ~ 50V（可编程） |
| 额定功率 | 300W |
| 开关频率 | 200kHz |
| 主控芯片 | STM32G474RBT6 (170MHz Cortex-M4) |
| 效率峰值 | 93.6% |
| 拓扑 | 四开关 Buck-Boost  |

## 2. 拓扑选择与方案设计

### 2.1 为何选择四开关 Buck-Boost

四开关 Buck-Boost 拓扑相比传统方案具有以下优势：

- **单电感设计**：仅需一个功率电感，体积和成本优于 SEPIC/Zeta
- **升降压平滑过渡**：通过 PWM 相位调制，在 Buck 和 Boost 模式之间零冲击切换
- **可直接关断**：传统的Boost电路或工作在Boost模式下的Buck-Boost电路，由于上管的体二极管方向由输入指向输出，故即使下管PWM为0，输入电压也会通过体二极管流向输出端
- **双向功率流**：支持双向工作，适合电池充放电应用

### 2.2 工作模式

| 模式 | 条件 | 工作状态 |
|------|------|----------|
| Buck 模式 | V_in > V_out | Q1/Q2 PWM斩波，Q3常通，Q4常断 |
| Boost 模式 | V_in < V_out | Q1常通，Q2常断，Q3/Q4 PWM斩波 |
| Buck-Boost 模式 | V_in ≈ V_out | 四管均参与调制，实现平滑过渡 |
| 直通模式 | V_in = V_out | Q1/Q3常通，Q2/Q4常断（最高效率） |

## 3. 硬件设计要点

### 3.1 功率器件选型

| 器件 | 型号 | 关键参数 |
|------|------|----------|
| Q1/Q2 (高压侧) | CJAC80SN10 | 100V / 6.7mΩ / PG-TDSON |
| Q3/Q4 (同步整流) | CJAC80SN10 |100V/6.7mΩ /  PG-TDSON |
| 电感 | 1770贴片 | 33μH / 13A饱和 / DCR=4.2mΩ |
| 输入电容 | 2×4.7μF MLCC + 2×330μF 高频电解 | 100V X7R |
| 输出电容 | 2×4.7μF MLCC + 2×330μF 高频电解 | 100V X7R |

### 3.2 驱动电路

使用 **EG2104** 半桥驱动芯片（带自举），Q1/Q2 和 Q3/Q4 各组成一个半桥：

- 自举电容：1μF / 50V X7R
- 栅极驱动电阻：2.2Ω（开通）/ 1Ω（关断，通过二极管旁路）
- 死区时间：硬件默认 50ns，软件可调

### 3.3 电流采样

采用 **INA240** 双向电流检测放大器（增益 50V/V），配合 5mΩ 采样电阻：

- 满量程范围：±24A
- 带宽：400kHz
- 输出接 STM32G431 内置 12-bit ADC（差分模式）

### 3.4 辅助电源

从输入取电，使用 MP2456 降压至 5V，再经 LDO 提供 3.3V 给 MCU。

## 4. 数字控制策略

### 4.1 控制架构

采用 **平均电流模式 + 电压外环** 的级联 PI 控制结构：

```
V_ref ──→ [PI 电压环] ──→ I_ref ──→ [PI 电流环] ──→ 占空比 ──→ PWM
           ↑                              ↑
        V_out ADC                      I_L ADC
```

### 4.2 模式切换逻辑

```c
// 模式判断与平滑过渡
if (V_in > V_out + 2.0f) {
    mode = MODE_BUCK;          // 降压模式
} else if (V_out > V_in + 2.0f) {
    mode = MODE_BOOST;         // 升压模式
} else {
    mode = MODE_BUCK_BOOST;    // 升降压过渡区
}
```

在 Buck-Boost 过渡区采用**相位偏移调制**，使 Q1/Q2 和 Q3/Q4 的 PWM 相位相差 180°，减小输入/输出电流纹波。

### 4.3 STM32G431 外设配置

| 外设 | 用途 |
|------|------|
| HRTIM (高精度定时器) | 4路互补 PWM 输出（184ps 分辨率） |
| ADC1/ADC2 (双ADC同步) | V_in、V_out、I_L、温度采样 |
| DAC | 调试输出（输出内部变量到示波器） |
| UART | 串口监控与参数调节 |
| COMP (模拟比较器) | 硬件过流保护（逐周期限流） |

### 4.4 保护功能

| 保护类型 | 实现方式 |
|----------|----------|
| 输入欠压 | ADC 检测，软件关闭 |
| 输出过压 | ADC + 比较器硬件触发 HRTIM 刹车 |
| 逐周期过流 | COMP 模拟比较器直接关断 PWM |
| 过温 | NTC 温度检测，降功率运行 |
| 短路保护 | 打嗝模式 (Hiccup)，200ms 自动重试 |

## 6. 问题与改进

### 6.1 过渡区振荡问题

**现象**：在 V_in ≈ V_out 的过渡区，输出电压出现 ±200mV 振荡。

**原因分析**：模式切换滞后导致占空比计算不连续，Buck/Boost/Buck-Boost 三种模式的占空比传递函数不同。

**解决方案**：
1. 在过渡区引入 ±2V 的迟滞窗口
2. 模式切换时冻结 PI 积分器 5 个开关周期
3. 过渡区使用双调制（Q1/Q2 和 Q3/Q4 同时调制），实现占空比连续变化

### 6.2 轻载效率优化

**现象**：输出 <10W 时效率骤降至 <80%。

**解决方案**：
- 实现**脉冲跳跃模式 (Pulse Skipping)**：轻载时跳过部分开关周期
- 使用**二极管仿真模式 (DEM)**：禁止同步整流管反向导通
- 优化后轻载效率提升至 >90%

### 6.3 热管理

满载 300W 时，下管 Q4 温度最高达 95°C（环境 25°C）。后续版本改用底部散热 PCB（2oz 铜厚 + 导热过孔阵列），温度降至 72°C。

## 7. 总结

本项目验证了 **STM32G431C8T6** 在数字电源中的优秀性能：

- **HRTIM 高精度 PWM**（184ps）几乎消除极限环振荡
- **内置比较器 + DAC** 实现无需外部运放的峰值电流控制
- **M4 内核 @170MHz** 有余量运行复杂控制算法（PI 仅占 <5% CPU）

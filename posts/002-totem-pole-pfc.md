# 图腾柱无桥PFC数字控制方案

## 1. 项目背景

传统 Boost PFC 的整流桥在低压大电流应用中损耗显著（以 1.5kW 为例，整流桥损耗可达 15W+）。**图腾柱无桥 PFC** (Totem-Pole Bridgeless PFC) 消除了输入整流桥，用开关管替代低频整流二极管，大幅降低导通损耗。本项目采用 GaN HEMT + DSP 数字控制方案，实现高效率、高功率因数的 AC-DC 前端。

| 参数 | 指标 |
|------|------|
| 输入电压 | 85 ~ 265V AC (47-63Hz) |
| 输出电压 | 400V DC |
| 额定功率 | 1.5kW |
| 开关频率 | 100 kHz (GaN 快管) / 50Hz (工频管) |
| 功率因数 | > 0.99 (满载) |
| THD | < 5% (满载) |
| 峰值效率 | 98.5% |
| 主控芯片 | TMS320F280049C |
| 功率器件 (快管) | GaN Systems GS66508B (650V/30A) |

## 2. 图腾柱 PFC 工作原理

图腾柱 PFC 由两个桥臂组成：**快管桥臂**（高频 GaN 开关管）负责 Boost 斩波实现 PFC 功能；**工频桥臂**（低频 Si MOSFET）在交流正负半周期交替导通，提供电流回路。

在交流正半周（L > N）：
- 工频管 Q3 常通，Q4 截止
- Q1 (GaN) 导通 → 电感储能 (iL↑)
- Q1 关断 → 电感通过 Q2 体二极管向输出释能 (iL↓)

在交流负半周期，Q3/Q4 角色互换，Q2 担任主开关。

关键挑战在于**过零点附近的电流尖峰** —— 工频管切换时体二极管反向恢复导致桥臂直通风险。解决方案：在电压过零点插入 2μs 的 **死区 Blanking**，期间禁止 GaN 管开关。

## 3. 数字控制算法

### 3.1 平均电流模式控制

采用双环控制：电压外环（10Hz 带宽，抑制 100Hz 纹波） + 电流内环（5kHz 带宽）。电流参考值由电压环输出乘以输入电压前馈信号得到：

```
Iref = Vloop_out × |Vin_sin| / Vrms²

// 其中 Vloop_out 为电压环 PI 输出
// Vin_sin 为归一化输入电压正弦波
// 除以 Vrms² 实现输入电压前馈补偿
```

### 3.2 数字锁相环 (PLL)

使用改进型 SOGI-PLL (二阶广义积分器锁相环)，对输入电压进行正交信号生成和锁相。SOGI 对谐波不敏感，在电网畸变时仍能稳定锁相：

```c
// SOGI 离散化实现
typedef struct {
    float k;            // 阻尼系数 (典型值 1.414)
    float w0;           // 谐振频率 (2*PI*50)
    float Ts;           // 采样周期
    float v_alpha;      // 同相输出
    float v_beta;       // 正交输出
    float integral;     // 积分状态
} SOGI;

void SOGI_Update(SOGI *sogi, float vin, float *alpha, float *beta) {
    float err = vin - sogi->v_alpha;
    sogi->integral += sogi->Ts * sogi->w0 * sogi->v_beta;
    sogi->v_beta += sogi->Ts * (sogi->k * err - sogi->integral) * sogi->w0;
    sogi->v_alpha = sogi->integral;
    *alpha = sogi->v_alpha;
    *beta = sogi->v_beta;
}
```

### 3.3 占空比前馈

加入占空比前馈可减轻电流环 PI 的调节负担，提升动态响应。前馈占空比由电感伏秒平衡推导：

```
d_ff = 1 - |Vin| / Vout
d_total = d_ff + d_pi  // PI 输出仅为修正量
```

## 4. GaN 驱动电路设计

GaN HEMT 对驱动要求严苛：Vgs 最大 7V、阈值仅 1.5V 左右、开启速度极快 (dV/dt > 100V/ns)。设计中注意：

- 驱动电压：+6V / -3V 负压关断，防止误导通
- 驱动芯片：Si8271 隔离驱动，带 UVLO
- 驱动回路面积 < 0.5cm²，栅极串联阻尼电阻 2.2Ω
- 在 GaN 漏源之间添加 RC Snubber (100pF + 10Ω) 抑制振铃

## 6. 踩坑记录

### 坑 1: 过零点电流尖峰

在交流电压过零点附近，工频管进行切换时，体二极管反向恢复电流导致 100A+ 的瞬时电流尖峰。
**根因**：死区不够，导致瞬间桥臂直通。
**解决**：在过零点前后各设置 100μs 的 Blanking 区，期间禁止 GaN 开关。

### 坑 2: GaN 管振荡烧毁

上电调试时一颗 GaN 管在轻载下烧毁。**根因**：漏源电压振铃超过 650V 额定值。PCB 布局中功率回路电感过大 (~15nH)，在 GaN 关断瞬间与结电容谐振。
**解决**：优化 Layout，功率回路面积缩小 50%；增加 RC Snubber 吸收振铃。

## 7. 总结

图腾柱无桥 PFC 配合 GaN 器件在效率和功率密度上远超传统方案，但对驱动电路和 PCB 布局要求极高。数字控制方案（SOGI-PLL + 平均电流模式）能够很好地应对电网畸变和负载突变。后续计划尝试 CCM/DCM 混合模式以提升轻载效率。

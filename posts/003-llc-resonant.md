# 全桥LLC谐振变换器数字控制

## 1. 项目背景

LLC 谐振变换器凭借全负载范围 ZVS（零电压开关）和副边 ZCS（零电流关断）特性，在高效隔离型 DC-DC 应用中占据主导地位。本项目设计一台 1kW 全桥 LLC，采用 DSP 数字控制，实现自适应死区调节与轻载 Burst 模式，面向工业电源模块应用。

| 参数 | 指标 |
|------|------|
| 输入电压 | 380V ~ 420V DC (PFC 母线) |
| 输出电压 | 48V DC (隔离) |
| 额定功率 | 1kW |
| 谐振频率 | 150 kHz |
| 工作频率范围 | 80 kHz ~ 250 kHz |
| 峰值效率 | 96.5% |
| 主控芯片 | TMS320F280049C |
| 变压器 | PQ4040, 初级:次级 = 18:4 (中心抽头) |

## 2. LLC 谐振参数设计

### 2.1 谐振网络参数

设计目标：额定输入 400V，输出 48V/21A。变压器匝比：

```
n = Vin_nom / (2 × Vout) = 400 / (2 × 48) ≈ 4.17
实际取 n = 18:4 = 4.5（略高，留调压余量）
```

等效负载电阻（归算至初级）：

```
Rac = 8 × n² × Rload / π²
    = 8 × 4.5² × (48²/1000) / π²
    ≈ 8 × 20.25 × 2.304 / 9.87
    ≈ 38 Ω
```

选取 k = Lm/Lr = 6（效率与调压范围的折中），Q = 0.45（满载）：

```
Lr = Q × Rac / (2π × fr) = 0.45 × 38 / (2π × 150k) ≈ 18.1 μH
Cr = 1 / (2π × fr × Q × Rac) = 1 / (2π × 150k × 0.45 × 38) ≈ 62 nF
Lm = k × Lr = 6 × 18.1 ≈ 108.6 μH
```

实际取值：Lr = 18μH（外置谐振电感，PQ2625），Cr = 60nF（2×30nF 并联，额定 630V），Lm = 110μH（变压器励磁电感）。

### 2.2 ZVS 条件验证

死区时间内励磁电流需完成 MOS 结电容的充放电：

```
Im_pk = n × Vout / (4 × Lm × fr) = 4.5 × 48 / (4 × 110μ × 150k) ≈ 3.27A
Tdead_min = 2 × Coss × Vin / Im_pk
          = 2 × 200p × 400 / 3.27 ≈ 49 ns
```

实际死区设为 200ns，留有充足余量。

## 3. 数字控制实现

### 3.1 变频控制架构

LLC 通过改变开关频率调节输出电压：频率升高→增益下降→输出电压降低；频率降低→增益上升→输出电压升高。采用**电压闭环 PI 控制器**直接输出开关频率：

```c
// LLC 频率控制
fsw = f_nom - PI_Update(pi, Vref, Vout_fb);

// 频率限幅
if (fsw > FSW_MAX) fsw = FSW_MAX;   // 250 kHz (轻载限制)
if (fsw < FSW_MIN) fsw = FSW_MIN;   // 80 kHz  (防止进入 ZCS 区)
```

### 3.2 自适应死区控制

根据负载电流实时计算最佳死区时间：满载时需要较小死区（减小体二极管导通损耗），轻载时需要较大死区（确保 ZVS）。用查表法实现：

```c
// 自适应死区查表 (Iload: 0~21A → Tdead: 300ns~120ns)
const float deadtime_LUT[] = {300, 240, 200, 170, 150, 130, 120, 120};
uint8_t idx = (uint8_t)(Iload / 3.0f);  // 每 3A 一档
if (idx > 7) idx = 7;
Tdead = deadtime_LUT[idx];
```

### 3.3 Burst 模式（轻载）

当负载低于 5%（约 50W）时，频率已达到上限。继续提高频率会增加开关损耗且效果有限。此时进入 **Burst 模式**：间歇性开关，每 N 个开关周期后停止 M 个周期，降低平均开关损耗：

```c
// Burst 模式控制
if (fsw_request > FSW_MAX) {
    // 进入 Burst 模式
    float burst_duty = (fsw_request - FSW_MAX) / (FSW_BURST - FSW_MAX);
    burst_on_cycles = 20;
    burst_off_cycles = (uint16_t)(burst_on_cycles / burst_duty - burst_on_cycles);
    if (burst_off_cycles > 200) burst_off_cycles = 200;  // 限制最大 off 周期
}
```

### 3.4 同步整流控制

副边采用中心抽头全波整流 + 同步整流 MOSFET。SR 驱动信号由 DSP 根据初级开关状态和谐振电流过零检测产生，需要补偿驱动和信号传输延迟（约 150ns）。

## 4. 保护功能

- **过流保护 (OCP)**：谐振电流逐周期检测，超过阈值 (30A) 立即关闭 PWM
- **过压保护 (OVP)**：输出 > 55V 触发保护
- **过温保护 (OTP)**：变压器和 MOS 温度 > 100°C 降额运行
- **容性模式保护**：检测电流相位，防止进入容性区（ZCS 丢失，开关损耗剧增）
- **软启动**：从 250kHz 逐步降到工作频率，限制启动冲击电流

## 6. 问题与改进

### 问题 1: 启动时谐振电流过冲

**现象**：上电瞬间谐振电流峰值超过 40A，触发 OCP。
**根因**：启动时输出电容电压为 0，谐振网络直接面对短路负载，增益极高。
**解决**：从 250kHz 开始扫频下降，同时限制频率下降速率 (1kHz/ms)，使输出电压平滑建立。

### 问题 2: 同步整流误导通

**现象**：轻载时 SR MOSFET 误开通，导致电流倒灌。
**根因**：DCM 下谐振电流有过零振荡，SR 检测电路误判。
**解决**：轻载时关闭 SR，仅使用体二极管整流；负载 > 20% 后再开启 SR。

## 7. 总结

本项目实现了一款全数字控制的全桥 LLC 谐振变换器，1kW 额定功率下峰值效率 96.5%。数字控制实现了自适应死区、轻载 Burst 模式以及完善的保护功能。LLC 的参数设计（k 值、Q 值选择）需要在效率、调压范围和器件应力之间权衡，FHA (基波近似) 只能作为起点，实际调优需要大量仿真和实验迭代。
